# Памятка RMRP — обновления

Здесь лежат данные, которые программа «Памятка RMRP» скачивает сама.

| Файл | Что это |
|---|---|
| `manifest.json` | версия и хеши — программа смотрит сюда первым делом |
| `zakonka.json` | тексты законов с форума |
| `guides.json` | памятки: порядок задержания, шпаргалка, оружие |
| `nlpmodel.json` | обученная модель для помощника |
| `legal_items.png` | таблица легальных масок и оружия |
| `Pamyatka-RMRP.exe` | сама программа |

Адрес обновлений в настройках программы:

```
https://raw.githubusercontent.com/vadimran1/-/main/
```

Выпуск новой версии: `python publish.py --app "что изменилось"`,
затем залить содержимое папки `release\` сюда.
